**Small-Office-Network**

## Project Overview
A small office network designed and simulated in Cisco Packet Tracer to practise fundamental networking concepts and troubleshooting.

## Objectives
- Configure VLANs for departmental network segmentation.
- Implement inter-VLAN routing using router-on-a-stick.
- Configure DHCP pools on the router for automatic IP assignment.
- Configure trunk links between switches and the router.
- Apply and test Access Control Lists (ACLs).
- Verify connectivity and troubleshoot network issues.

## Network Design

| Department | VLAN | Network | Default Gateway |
|---|---:|---|---|
| HR | 10 | 192.168.1.0/24 | 192.168.1.1 |
| IT | 20 | 192.168.2.0/24 | 192.168.2.1 |
| Finance | 30 | 192.168.3.0/24 | 192.168.3.1 |

## Devices
- 1 Cisco router
- 2 Cisco switches
- 3 end devices

## Technologies
- Cisco Packet Tracer
- VLANs and 802.1Q trunking
- Router-on-a-stick
- DHCP
- Extended ACLs
- Basic network troubleshooting

## Testing
Connectivity and ACL behaviour will be documented with screenshots after configuration and verification.
